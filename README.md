# PinBean 拼豆工具

把图片转成拼豆图纸，修改豆色，查看材料用量，并导出图纸。

## 启动前准备

安装 Node.js 22.12 或更高版本，建议使用 Node.js 24 LTS。
安装后重新打开终端。

## Windows 启动

双击项目文件夹里的 `启动工作台.cmd`。

第一次启动会下载依赖，需要联网。等待安装完成后，浏览器会自动打开。
使用时保持命令窗口打开，关闭窗口即可停止运行。

**网页打开后就可以使用，不需要再执行下面的命令。以后也只需双击 `启动工作台.cmd`。**

## 备用方法 用命令启动

如果不使用启动脚本，也可以按下面的方法启动。两种方法选一种即可。

在项目文件夹中打开终端，依次输入：

```sh
npm ci
npm run dev
```

浏览器打开终端中显示的地址，通常是 `http://127.0.0.1:5173/`。
以后启动只需输入 `npm run dev`。停止运行时按 `Ctrl+C`。

## 开发者选读 检查和构建

以下命令用于检查代码和生成网页文件，正常使用时不需要执行。

```sh
npm test
npm run build
```

如需查看构建结果，再运行 `npm run preview`，打开终端显示的地址。
不要直接双击 `index.html`。

## 如何使用

详细操作见同目录的 `PinBean使用说明.docx`。
图片在浏览器本地处理，图纸会自动保存在当前浏览器中。建议定期下载工程备份。

色盘数据的来源和授权说明见 `THIRD_PARTY_NOTICES.txt`。
